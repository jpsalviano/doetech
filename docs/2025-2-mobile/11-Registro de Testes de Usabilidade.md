## Relatório dos testes de usabilidade 

Aviso! Os testes de usabilidade referentes aos cenários 3 e 4 não foram conduzidos pois a funcionalidade correspondente a cada um deles não foi implementada nesta iteração do DoeTech. Desta forma, não foram considerados para as análises posteriores.

Como resultado parcial, podemos destacar:

* Os usuários conseguiram executar as ações dentro do período proposto, sem auxílio;
* Todos os usuários deram feedback positivo sobre a experiência nos testes, como cadastro, autenticação, navegação nas páginas da aplicação e no cadastro de equipamentos;
* Percebemos que a imagem dos equipamentos é necessária. Neste momento, não temos um cadastro de imagens na aplicação. Entretanto, o backend já suporta esta funcionalidade;
* A tela de edição de doações é necessária e será implementada em iteração posterior;
* A tela de dashboards, disponível apenas a usuários administradores, foi exibida para todos os usuários que testaram a aplicação. Um dos usuários não compreendeu os gráficos e métricas apresentados. Como este não é o público-alvo dos dashboards, esse feedback foi desconsiderado;
